📖 Guía — ReporteMensual

¿Qué es?

Aplicación web offline para gestionar reportes de trabajos. Funciona sin internet y guarda todo en tu dispositivo.

🚀 Primeros pasos

  1. Al entrar por primera vez, ingresa tu nombre.
  2. Verás dos módulos de ejemplo.
  3. Usa el botón ⚙️ Menú Principal para todas las acciones.

➕ Crear un módulo

  1. Menú → Nuevo Módulo.
  2. Ponle nombre, ícono y color.
  3. Agrega los campos que necesites.
  4. Guarda. ¡Listo!

📥 Importar desde Excel

  1. Menú → Crear Módulo desde Excel.
  2. Selecciona el archivo.
  3. Ajusta las columnas.
  4. Pulsa "Crear módulo".

📝 Registrar trabajos

  1. Pulsa + Nuevo Registro o Alt+N.
  2. Rellena los campos.
  3. Guarda con Ctrl+S.

💾 Backup (¡CRÍTICO!)

Los datos viven en tu navegador. Si borras caché, se pierden. Haz Backup semanal con Menú → Backup JSON.

⌨️ Atajos

  • Alt+N → Nuevo registro
  • Ctrl+S → Guardar
  • Esc → Cerrar

📱 Instalar en celular

  • Android: Menú del navegador → "Instalar app".
  • iPhone: Compartir → "Añadir a pantalla de inicio".
